MC generation pipeline quickstart

Tool instructions and documentation for the group's HEP and Monte Carlo pipelines.

Start here

Producing Monte Carlo events needs two things: the generators themselves (MadGraph5_aMC@NLO, MadSpin, Pythia 8 and Rivet), and optionally something to help drive them through the whole chain. This guide therefore comes in two stages — first set up an environment that has the generators installed, then install and run the pipeline that ties them together. If you already have the tools, you can skip straight to the second stage.

  1. Get a software environment. If MadGraph, MadSpin, Pythia and Rivet are not installed yet, set up the HEP Software Environment:
    • on an HPC cluster with Apptainer (e.g. AUTh's Aristotle) — Apptainer guide;
    • locally on Linux or WSL — Docker guide.
  2. Install and run mg-pipeline. Once the environment is ready (or if you already have one), follow the mg-pipeline guide to run your first production.

Something not working? See troubleshooting.
