MC generation pipeline quickstart

Tool instructions and documentation for the group's HEP and Monte Carlo pipelines.

Start here

If you don't have a working environment with MadGraph, MadSpin, Pythia and Rivet installed, start here. Get a working environment first, then install the pipeline driver:

  • If you are working in an environment with Apptainer available (e.g. AUTh's Aristotle HPC), see the Apptainer guide.
  • If you are working locally on Linux or WSL, see the Docker installation guide.

When your environment is running, install mg-pipeline and run your first production. mg-pipeline can also run standalone if the tools are already installed, but the environments above are what we propose. If something goes wrong, see troubleshooting.
