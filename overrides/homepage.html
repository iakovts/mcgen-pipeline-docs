The intended path for new users — follow the steps in order:

    Get a development environment

    Set up the HEP Software Environment — the MadGraph → MadSpin → Pythia → Rivet stack, on the HPC (Apptainer) or on a workstation (Docker).

  2. 2

    Install and run mg-pipeline

    The pipeline driver: give it your config cards and it runs the stages for you. Runs standalone too, if you already have the tools installed — but we recommend the environment above.

  3. 3

    Learn more

    Study guides and tool instructions for going deeper: physics background, cards, stages, and day-to-day workflows.
