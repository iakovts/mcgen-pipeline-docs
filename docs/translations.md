# Ελληνική μετάφραση — σύντομα κοντά σας

Η ελληνική μετάφραση αυτής της τεκμηρίωσης είναι **στα σχέδια** και θα προστεθεί
σε επόμενη φάση.

Προς το παρόν ο ιστότοπος είναι διαθέσιμος στα **Αγγλικά**. Όταν ολοκληρωθεί η
μετάφραση, θα εμφανιστεί επιλογέας γλώσσας (Ελληνικά / English) στην κορυφή της
σελίδας και η ελληνική έκδοση θα είναι διαθέσιμη στο `/el/`.

!!! note "In English"
    The Greek translation is planned but not yet available — the site is
    currently English only. A language switcher (Ελληνικά / English) will
    appear once the translation is ready, with the Greek build served under
    `/el/`.
